# 멸종위기동물 AR 보금자리 관찰 - 투명 영상 버전

## 포함 동물 영상
- 반달가슴곰: `assets/videos/bear.webm`
- 노루: `assets/videos/deer.webm`
- 수달: `assets/videos/otter.webm`

## 사용 방법
1. 이 폴더 안의 파일을 GitHub 저장소 root에 업로드합니다.
2. `index.html`, `style.css`, `app.js`, `assets` 폴더가 저장소 첫 화면에 바로 보여야 합니다.
3. GitHub Pages 주소를 Chrome에서 엽니다.
4. 카메라 권한을 허용하고, 작품에 붙인 동물 표찰을 비춥니다.
5. 표찰별로 움직이는 투명 WebM 동물 영상이 나타납니다.

## 영상 파일 매핑
- 사용자가 올린 1번째 영상 → 수달
- 사용자가 올린 2번째 영상 → 노루
- 사용자가 올린 3번째 영상 → 반달가슴곰

## 주의
- Android Chrome 기준으로 테스트하는 것이 가장 안전합니다.
- 캐시 때문에 예전 화면이 나오면 주소 뒤에 `?v=20260817-video`를 붙여 열어 보세요.
- 영상이 너무 무겁게 느껴지면 720×720 WebM으로 낮춰 다시 넣으면 안정성이 좋아집니다.
